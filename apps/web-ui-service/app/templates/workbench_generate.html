一键自动测试

  1. 输入被测页面 URL，可一次输入一个或多个页面。
  2. 需求描述现在是可选项；不填写时，系统会根据页面自动生成默认测试目标。
  3. 点击“一键自动生成并执行”，系统会自动完成测试点、页面对象、用例、执行与报告刷新。

returnApply 回流路径

1. 从首页进入样板

仪表盘和工作台都提供 returnApply 样板 入口，方便直接复现主链路。

2. 载入后先预览

样板会自动填充页面 URL、标题、优先级、标签和回归目标，便于先检查字段是否符合预期。

3. 生成后回工作台

生成成功后可以直接进入预览，也能回到工作台定位同一个用例，继续看 YAML、日志和结果。

4. 执行后看 run 回流

如果是自动执行，工作台会带着 run_id 回流，继续查看实时日志、失败分析和审计时间线。
