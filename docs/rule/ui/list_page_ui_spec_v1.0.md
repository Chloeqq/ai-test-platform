# AI自动化测试平台列表页统一交互规范 v1.0

## 1. 适用范围
适用于平台所有“列表型页面”，包括：
- 用例中心
- AI生成历史
- 执行任务
- 执行结果
- 质量分析
- 资产管理
- 系统配置

---

## 2. 标准页面结构

所有列表页必须包含以下结构：

1. 页面标题区（标题 + 描述 + 主操作）
2. 工具栏区（搜索 / 筛选 / 刷新 / 列设置）
3. 批量操作区（选中后出现）
4. 表格区（核心数据展示）
5. 分页区（底部）

---

## 3. 搜索规范

必须支持：
- 关键词搜索
- 回车触发
- 清空按钮
- 保留搜索条件

占位文案必须明确：
例如：
- 搜索用例ID / 标题 / 标签
- 搜索 run_id / 计划名

---

## 4. 筛选规范

分为两层：

### 快捷筛选（默认展示）
- 状态
- 类型
- 来源
- 页面/模块

### 高级筛选（折叠）
- 时间范围
- 创建人
- 标签
- 其他低频字段

必须支持：
- 一键重置
- 当前筛选可见
- 条件保留

---

## 5. 排序规范

允许排序字段：
- 创建时间
- 更新时间
- 优先级
- 状态
- 执行时长

规则：
- 默认排序必须明确
- 仅支持单列排序

---

## 6. 刷新规范

必须支持：
- 手动刷新
- 保留当前筛选条件
- 显示“最后刷新时间”

执行类页面建议支持：
- 自动刷新（5s/10s/30s）

---

## 7. 分页规范

必须支持：
- 总条数
- 页码切换
- 每页条数（10/20/50/100）
- 快速跳页

默认：
- 管理页：20
- 执行页：50

---

## 8. 删除与归档规范

推荐：

### 用例
- 禁止物理删除
- 使用“归档/废弃”

### 执行记录
- 不允许删除（或仅管理员）

### 生成历史
- 可删除

交互要求：
- 二次确认
- 显示影响范围
- 成功提示

---

## 9. 批量操作规范

必须支持：
- 多选
- 全选当前页
- 清空选择

常见操作：
- 批量归档
- 批量删除
- 批量打标
- 批量审核

---

## 10. 表格规范

要求：
- 支持排序列
- 状态标签
- 操作列固定
- 行点击查看详情

操作列建议：
- 查看
- 编辑
- 更多

---

## 11. 空状态规范

必须提供引导：

示例：
- “暂无用例，去AI生成”
- “暂无执行任务，去创建计划”

---

## 12. 加载状态规范

必须支持：
- 骨架屏
- loading状态
- 防止白屏

---

## 13. 权限控制

不同角色权限不同：
- QA：编辑/提交审核
- Lead：发布/批量审核
- Admin：删除/归档

---

## 14. 前端组件建议

统一组件：

components/list-page/
- ListPageLayout.tsx
- ListToolbar.tsx
- SearchBox.tsx
- Filters.tsx
- BatchActionBar.tsx
- Pagination.tsx

---

## 15. 后端接口规范

请求：

{
  "page_no": 1,
  "page_size": 20,
  "keyword": "",
  "filters": {},
  "sort": {
    "field": "updated_at",
    "order": "desc"
  }
}

响应：

{
  "code": "SUCCESS",
  "message": "ok",
  "data": {
    "list": [],
    "page_no": 1,
    "page_size": 20,
    "total": 100
  },
  "trace_id": "xxx"
}

---

## 16. 检查清单

每个列表页必须满足：

- [ ] 可搜索
- [ ] 可筛选
- [ ] 可排序
- [ ] 可刷新
- [ ] 可分页
- [ ] 支持批量操作
- [ ] 支持安全删除/归档
- [ ] 有空状态
- [ ] 有加载状态
- [ ] 保留查询条件

---

## 17. 总结

列表页不是简单表格，而是平台核心交互。

必须做到：
- 统一体验
- 统一结构
- 统一接口
- 统一组件

否则系统会快速失控。
