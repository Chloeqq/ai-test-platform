# 页面对象治理低保真线框 V1.0

## 说明

本文将页面对象治理方案细化为低保真页面线框，目标是明确：

- 页面布局层级
- 信息区块顺序
- 高频操作入口
- 页面之间的跳转关系

本文只描述结构和交互，不限定最终视觉风格。

---

## 1. 页面对象列表页

页面：`PageObjectsPage`

### 1.1 页面骨架

```text
+--------------------------------------------------------------------------------------------------+
| 页面对象                                                                                  [新建页面对象] |
| 管理页面资产、录制历史与元素治理状态                                                            |
+--------------------------------------------------------------------------------------------------+
| [页面总数] [已治理页面数] [待审候选组总数] [平均可测试性评分]                                      |
+--------------------------------------------------------------------------------------------------+
| 项目[____] 端类型[web v] 模块[____] 页面状态[v] 治理状态[v] 关键词[__________] [查询] [重置]     |
+--------------------------------------------------------------------------------------------------+
| 页面编码 | 页面名称 | 页面地址/Route | 正式元素数 | 待审候选组 | 关键元素覆盖率 | 可测试性 | 状态 | 操作 |
|----------|----------|----------------|------------|------------|----------------|----------|------|------|
| login    | 登录页   | /login         | 12         | 4          | 75%            | 82/100   |治理中 | 查看元素 |
|                                                                                           开始录制 |
|                                                                                           编辑页面 |
|                                                                                           删除     |
+--------------------------------------------------------------------------------------------------+
| 分页                                                                                               |
+--------------------------------------------------------------------------------------------------+
```

### 1.2 布局说明

- 第一屏必须看到统计卡和表格首屏数据
- 操作列固定在右侧
- `待审候选组`、`关键元素覆盖率`、`可测试性评分` 三列必须同时可见

### 1.3 交互说明

- 点击页面名称：进入元素列表页
- 点击查看元素：进入元素列表页
- 点击开始录制：进入录制页
- 点击编辑页面：打开编辑弹窗
- 点击删除：二次确认弹窗

+--------------------------------------------------------------------------------------------------+
| [当前会话状态]                                      | [最近录制历史]                               |

| 启动时间: 2026-04-27 10:00                          | xxx   |停止  | 18     | 6      | ...  | 回放 |
| 心跳时间: 2026-04-27 10:03                          |                                          去审核 |
| 脚本路径: /artifacts/...                            |                                          stderr |
| stderr 摘要: ...                                    |                                                |
|                                       [停止录制]    |                                                |
+--------------------------------------------------------------------------------------------------+
| [停止录制后的结果卡]                                                                                |
| 会话状态: 已停止                                                                                   |

### 2.2 交互重点

- 录制过程中页面不可空白，必须持续反馈会话状态
- 停止录制后，`去元素列表审核` 是唯一主按钮
- 历史列表中的 `去审核` 统一跳转到候选元素 Tab

## 7. 页面之间的跳转地图

```text
页面对象列表页
  -> 查看元素 -> 元素列表页 / 正式元素 Tab
  -> 开始录制 -> 录制页

录制页
  -> 去元素列表审核 -> 元素列表页 / 候选元素 Tab / 带 session_id
  -> 查看回放 -> 当前页回放抽屉

元素列表页
  -> 开始录制 -> 录制页
  -> 候选提升成功 -> 留在候选元素 Tab，可切正式元素 Tab 校验结果
  -> 录制历史去审核 -> 候选元素 Tab / 自动过滤 session_id
```

---

## 8. 最终建议

如果后续要继续出高保真稿，建议优先画这 4 个核心画面：

1. 页面对象列表页
2. 元素列表页-候选元素 Tab
3. 提升为正式元素弹窗
4. 录制页停止后的结果卡片

因为这 4 个画面已经覆盖了用户最核心的治理闭环。
