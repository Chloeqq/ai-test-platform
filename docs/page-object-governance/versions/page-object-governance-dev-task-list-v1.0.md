# 页面对象治理页面开发任务清单 V1.0

## 使用说明

本文按页面拆解字段、按钮、弹窗和开发任务，适合直接转成前端迭代任务。

---

## 1. 页面对象列表页

页面：`PageObjectsPage`

### 1.1 需要展示的字段

- 页面编码 `page_code`
- 页面名称 `page_name`
- 页面地址 / route `page_url` / `route_pattern`
- 正式元素数 `approved_element_count`
- 待审候选组数 `candidate_pending_count`
- 关键元素数量 `key_element_count`
- 可测试性评分 `testability_score`
- 治理状态 `governance_status`
- 更新时间 `updated_at`

### 1.2 按钮

- 新建页面对象
- 查询
- 重置
- 查看元素
- 开始录制
- 编辑页面
- 删除

### 1.3 弹窗

- 编辑页面对象弹窗
- 删除确认弹窗

### 1.4 开发任务

- 新增治理指标列
- 新增统计卡区域
- 统一操作列中文文案
- 打通“查看元素”跳转
- 打通“开始录制”跳转
- 编辑弹窗补齐治理字段

## 8. 通用交互任务

### 8.1 文案统一

- 顶部 `project_code` 改成 `项目`
- 操作列全部中文化
- Tab、按钮、提示语统一中文

### 8.2 状态样式

- 审核通过、稳定高：绿色
- 待审核、治理中：橙色
- 拒绝、失败、危险动作：红色
- 草稿、历史、无数据：灰色

### 8.3 空状态

- 正式元素为空提示去录制
- 候选为空提示当前无待审候选
- 录制历史为空提示尚无录制记录

### 8.4 成功提示

- 提升成功
- 合并成功
- 拒绝成功
- 跳转成功
