# 测试资产规范

这份文档定义测试点如何进入资产页，以及生成后如何分流到待审核用例。

## 1. 资产分层

- 测试点资产：处于第 3 步和第 4 步之间的数据
- 待审核用例：点击“生成用例”之后进入的平台审核链路
- 最终用例：通过审核后进入可执行用例中心

## 2. 流转原则

- 测试点资产和待审核用例必须分开管理
- 不允许把测试点资产直接等同于最终用例
- 点击生成用例后，才进入待审核链路
- 保存测试点资产时，只保存候选与分析结果

## 3. 保存规则

- `selected_candidates` 最多 20 条
- `page` 必须存在
- `case_id` 必须可归一化
- 候选步骤必须有结构化信息
- 缺少步骤或涉及元素时要给出警告

## 4. 文件与状态

- 测试点资产会落到 `web-ui/state/test-points`
- 生成后的用例状态会写入工作台状态和测试用例资产
- `assets/test-cases` 是最终用例侧的持久化位置

## 5. 与平台页面的关系

- 测试点资产页展示的是候选和中间结果
- 待审核用例列表展示的是生成后的审核对象
- 待审核用例详情展示的是生成后的单条完整数据
