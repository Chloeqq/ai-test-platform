## 2. 重复 Snapshot 风险

AI 生成和手工编辑是两个互斥入口，各自独立产生 1 个 snapshot。同一操作不会触发两次。**无重复风险。**

## 3. Version 一致性

- upsert 路径：从 asset 文件读取递增后的 version → 正确
- **ai_save 路径：bundle["version"] 固定为 1 → 始终 version=1**

修复：从现有 asset 文件读取 version +1。

## 4. 时间一致性

时序：file write → DB write → re-read → snapshot。snapshot 基于重新读取的数据，反映当前状态。**顺序正确。**

## 5. Failure 策略

当前：snapshot 失败仅 log warning，不阻断。**保持当前策略。**snapshot 是衍生数据，不应阻断 asset 保存。
