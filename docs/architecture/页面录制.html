状态转换图
空闲 ──[开始录制]──→ 录制中
                      ├──[停止]──→ 已停止 ──→ 候选审核页（现有流程）
                      └──[停止并执行]──→ 执行中
                                            ├──→ 通过 ✅ ──→ [提升] 或 [重跑] 或 [丢弃]
                                            ├──→ 失败 ❌ ──→ [自愈] 或 [重跑] 或 [丢弃]
                                            └──→ 超时 ⏱ ──→ [重跑+增加超时] 或 [丢弃]

[提升] → 候选→正式元素（单向门，不可逆）
[重跑] → 执行中（回到状态4）
[丢弃] → 空闲（删除临时用例和候选）
[自愈] → 弹窗显示预览，用户选择是否应用
错误处理
场景用户看到下一步
Codegen 未正常启动"录制启动失败：Playwright Codegen 未响应" + [重试]重试或手动启动
浏览器崩溃"录制中断" + 已录制步骤保留重新录制或基于已录制步骤执行
用例生成失败"用例生成失败：步骤无法转换" + 原因检查录制步骤
run_case 调度失败"执行调度失败：运行队列不可用" + [重试]重试
网络断开"连接中断，执行仍在进行" + [刷新状态]手动刷新
promote 失败"提升失败：元素已存在"逐个检查
