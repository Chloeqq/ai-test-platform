## 2. API 设计

### 2.1 GET /api/workbench/quality/summary

返回项目质量概览。snapshot 聚合 + 实时 fallback。

### 2.2 GET /api/workbench/quality/ranking

返回 Asset 排名，score ASC（最低质量优先）。

### 2.3 GET /api/workbench/quality/issues

返回 5 个 count 按 asset 聚合的问题分布。

### 2.4 GET /api/workbench/quality/timeline/{asset_id}

返回单 asset 时间线，逐行计算 delta_score。

- delta_score 仅 1 行时返回 0
