## P0 — 严重问题（必须修复）

### 1. delete_dataset 不级联删除，会造成孤儿数据或 FK 约束错误

**文件**：`apps/web-ui-service/app/repositories/quality_eval_repository.py:36-42`

```python
def delete_dataset(self, dataset_id: str) -> bool:
    ds = self.get_dataset(dataset_id)
    if ds is None:
        return False
    self.db.delete(ds)  # 只删了 dataset
    self.db.flush()
    return True
```

`QualityEvalItem` 有 `ForeignKey("quality_eval_datasets.dataset_id")`，`QualityEvalRun` 也有同样的 FK。直接删 dataset 时，PostgreSQL 会报 `ForeignKeyViolation`，SQLite 取决于 `PRAGMA foreign_keys` 设置。

**修复**：先删关联的 results → runs → items，再删 dataset。

**文件**：`apps/web-ui-service/app/services/quality_eval_service.py:590`

```python

```

CLAUDE.md 约束：`except Exception` 仅用于编排降级、DB 回滚、子进程容错。此处属于"编排降级"范畴，但应至少区分 `ValueError` / `TypeError`（代码逻辑错误，应 fail fast）和真正的运行时异常。
