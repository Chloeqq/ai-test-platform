## 2. 绕过路径

### 场景 A：Generate 后修改 Asset → Execute 原 case — MEDIUM

- **风险**: case 生成时的 asset 状态 ≠ 当前 asset 状态
- **评估**: case 的 `script_code` 是生成时固化到 DB 的，不会因后续 asset 修改而变化。如果 case 生成时通过了 Gate，它的 `script_code` 是合格的。后续 asset 修改不影响已生成的 case。这是正确行为，不需要修复。Execute Gate 应检查 case 自身的质量，而非追溯 asset。

### 场景 B：历史 Case 无 source_asset_id — LOW

- **文件**: `facade_test_point_assets.py:1456`
- **风险**: 老 case 的 YAML 可能没有 `requirement.source_asset_id` 字段
- **评估**: 老 case 的 `script_code` 本身已在生成时通过当时的质量检查。硬加 Gate 只会阻断存量用例。历史 case 应豁免。

### 场景 C：Rerun — MEDIUM

- **文件**: `facade_test_point_assets.py:1648`
- **当前行为**: `rerun_case` 直接调用 `self.run_case()`，无额外检查
- **评估**: 因为 rerun 最终走 run_case，修复 run_case 自动覆盖 rerun。不需要单独处理。

## 3. Case-Asset 关联评估

```
case.script_code (DB, YAML)
  │
  └── requirement:
        source_asset_id: "mall-web-login-auth-fn-ai-0001"  ← 存在

```

**追溯路径已验证可行：**
1. `_source_identity_from_case(case)` → 从 YAML `requirement.source_asset_id` 提取
2. `workbench_asset_service.load_test_point_asset_with_root()` → 加载 asset
3. `_build_quality_report(asset)` → 计算质量报告
4. `check_generate_gate(asset)` → 复用 Generate Gate

**限制**：仅当 `source_asset_id` 非空且 asset 文件存在时才可追溯。历史 case 可能无此字段。

## 4. Execute Gate 最小方案

### 规则设计

| 条件 | Execute 阻断 | 原因 |
|------|------------|------|
| source_asset_id 为空 | 跳过 Gate | 历史 case 豁免 |
| asset 加载失败 | 跳过 Gate | 文件缺失不阻断执行 |
| zero_assertion > 0 | block | 与 Generate/Review 一致 |
| unprocessed > 0 | block | 与 Generate/Review 一致 |
| quality_warning | 不阻断 | 提示性质，不阻止执行 |
| data_warning | 不阻断 | 数据不影响执行正确性 |

**与 Generate Gate 规则完全一致。**

### 实施位置

**方案 A**：在 `run_case:1481` 插入追溯检查

```
行 1481: script_code 非空检查之后  ← 插入点
行 1481+: 追溯 source_asset → 执行 check_generate_gate(asset)
```

**修改文件列表**：

| 文件 | 位置 | 改动 | 行数 |
|------|------|------|------|
| `facade_test_point_assets.py` | `run_case:1481` 之后 | source_asset 追溯 + `check_generate_gate(asset)` | +8 |

**风险评估**：

| 风险 | 缓解 |
|------|------|
| 历史 case 无 source_asset_id | 跳过 Gate，不影响存量 |
| asset 文件被清理 | 跳过 Gate，不阻断执行 |
| run_case 变慢 | `_build_quality_report` 纯计算，<1ms |
